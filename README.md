# Diondi LLC Website

Static website for https://diondi.org/.

## Files
- `index.html` — website content
- `styles.css` — all styling and responsive layout
- `favicon.svg` — browser tab icon
- `social-preview.svg` — social/link preview artwork
- `CNAME` — GitHub Pages custom domain

## Local preview
From this folder, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Publishing
Publish the repository with GitHub Pages from the `main` branch and `/ (root)`.
See the setup instructions provided in the ChatGPT conversation for DNS configuration.
